**PROGRAMA PARA EXPORTAR EXCEL A XML Y AUTORIZAR XML**
--- 
**Instrucciones**
1. Se debe instalar los paquetes para ello se debe abrir el instalador "INSTALADOR.bat".
2. Para ejectutar el programa "Exportar Excel a XML" se debe abrir el archivo "EJECUTAR_GENERADOR.bat y estos XML seran colocados en la carpeta "GENERADOS".
3. Para ejecturar la autorizacion de los XML se debe abrir el archivo "EJECUTAR_ENVIO.bat y estos XML estaran dentro de la carpeta .\FIRMADOS\AUTORIZADOS".
---
**NOTA**
1. Se debe usar el aplicativo comprobantes "ComprobantesDesktop.jar" para firmar los XML y colocarlos en la carpeta "FIRMADOS".
2. Para descargar los PDF's de los XML se debe usar el aplicativo "ComprobantesDesktop.jar" y colocar en la direccion .\FIRMADOS\AUTORIZADOS para visualizar los RIDE de los XML ya autorizados.
